Major Changes

Premium System

New Subscription Bundles

The older version did not have the final premium structure. The new version now separates premium access into clear bundles for circuit racing, rally racing, and the best-value all-access plan.

`Circuit / Formula Pro` includes F1 / F2 / F3, Go-Karting, GT Racing, Hypercar, and LMP / Le Mans.
`Rally Pro` includes rally track building with normal, stage, and raid rally formats.
`Apex Ultimate` combines every premium class into one plan.
Builder Upgrade

Manual Track Tags By Subscription

Premium users now see track tags inside the builder instead of the old free-mode text. The tag choices are based directly on the subscription that account has.

Circuit subscribers can select from the full circuit-class tag group.
Rally subscribers get rally tag controls and rally format options.
Free users can still build tracks, but premium users now get direct manual tag control.
Rally Logic

Rally Formats Now Behave Properly

The builder now respects the difference between closed and open rally layouts, so rally design no longer behaves like a normal closed circuit when it should not.

`Normal Rally SS` supports 1 to 2 km closed sections.
`Stage Rally` supports 3 to 50 km open sections with 300 to 350 km total event distance.
`Raid Rally` supports 100 to 800 km open sectors with 3,000 to 8,000 km total distance.
The close-circuit button is hidden for open rally formats.
Length Rules

Track Length Is Now Limited By Tag

The old fixed maximum length is gone. Track size now follows the chosen tag so each racing class has the correct build range.

F1 / F2 / F3, GT, Hypercar, and LMP follow 3 to 7 km rules.
Go-Karting follows 0.3 to 5 km rules.
Rally formats each use their own minimum and maximum ranges.
The builder now warns when the layout is too short or too long for the selected class.

Now

Subscription-Aware Builder
